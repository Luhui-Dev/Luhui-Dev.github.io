Gran actualización del SDK de Dino-GSP: exporta y distribuye contenido geométrico con más control

Producto: Pizarra de Geometría Dino-GSP

Version: SDK 2.10.0

Fecha de publicacion: 27 de julio de 2026

Ultima actualizacion: 27 de julio de 2026

Incrustar un tablero geométrico en un producto es solo el primer paso.

Cuando entra en un flujo de trabajo real, aparecen preguntas más concretas:

  • ¿Cómo adaptar el mismo diagrama a una miniatura, una ilustración de examen y una diapositiva de alta resolución?
  • ¿Cómo exportar un rango de coordenadas exacto sin ajustar el lienzo una y otra vez?
  • ¿Puede un diagrama seguir siendo editable después de entrar en un artículo o libro de texto?
  • ¿Por qué un tablero puede recuperar un tamaño incorrecto al reaparecer dentro de una pestaña, un panel lateral o una sección contraída?
  • ¿Puede una presentación conservar solo los controles que necesita cada escenario docente?

Todas estas preguntas apuntan al mismo reto: hacer que el contenido geométrico salga del tablero de forma fiable y entre en procesos reales de producción, enseñanza y entrega de producto.

Dino-GSP SDK 2.10.0 ya está disponible. Esta versión se centra en la exportación, la adaptación a diseños dinámicos y el modo de presentación, para que una misma fuente geométrica se adapte mejor a distintos dispositivos, formatos y escenarios.



Exportación de imágenes mejorada: entregar según el uso

Rara vez existe una única forma correcta de exportar una imagen para bancos de preguntas, material didáctico, exámenes y plataformas de contenido.

Una lista de preguntas necesita miniaturas uniformes. Una presentación necesita imágenes nítidas con márgenes equilibrados. Un examen necesita un encuadre estable. Algunas clases solo quieren mostrar una región concreta del sistema de coordenadas.

Dino-GSP SDK 2.10.0 añade tres modos a editor.slides.exportImage(options):

  • El modo size exporta con dimensiones especificadas, ideal para miniaturas, tarjetas y diapositivas de formato fijo.
  • El modo view exporta una vista de coordenadas del mundo seleccionada, con control preciso del encuadre y la escala.
  • El modo contain encierra automáticamente toda la construcción, reduciendo recortes y espacios desiguales al exportar recursos variados por lotes.

La API admite PNG, JPG y SVG, y ofrece más control con pixelRatio, padding, minPadding, quality y otros parámetros. Ya no es necesario mover el lienzo, cambiar el zoom o recortar cada resultado. Los mismos datos geométricos estructurados pueden generar el resultado visual adecuado para cada destino.



Exportación independiente a LaTeX/TikZ

Para libros de texto, exámenes y escritura académica, una imagen no siempre es el resultado final.

Las imágenes de mapa de bits no escalan sin pérdida y son costosas de modificar. Los formatos vectoriales generales conservan la nitidez, pero no siempre encajan con la tipografía y la composición de LaTeX. TikZ resuelve estos problemas, aunque escribirlo a mano exige tiempo y experiencia.

En 2.10.0, la exportación LaTeX/TikZ pasa a una API propia:

editor.slides.exportLatex(options)

La separación aclara las funciones de la exportación de imágenes y de código fuente, y permite crear flujos previsibles:

  • Exportar PNG, JPG o SVG para sitios web y presentaciones.
  • Exportar LaTeX/TikZ editable para artículos, apuntes y libros.
  • Generar varios formatos desde una misma fuente geométrica sin volver a dibujar para cada canal.

Para los equipos con grandes catálogos de matemáticas, no se trata solo de exportar más rápido. Los recursos geométricos pueden crearse una vez, reutilizarse en varios canales y mantenerse a largo plazo.



Redibujado automático en contenedores dinámicos

Los productos web modernos rara vez colocan el tablero en una página siempre visible y de tamaño fijo. Puede aparecer en un diálogo de edición, una pestaña, un panel lateral, una sección contraída o un espacio de trabajo redimensionable.

Dino-GSP SDK 2.10.0 añade resize() a EmbeddedEditor y EmbeddedPresentation, y utiliza ResizeObserver para seguir los cambios de tamaño. Cuando un contenedor oculto vuelve a ser visible, el SDK solicita automáticamente una nueva medición y un nuevo renderizado.

Esta mejora resulta especialmente útil para:

  • Sistemas de preguntas y plataformas docentes con varias pestañas
  • Herramientas de autoría que abren el tablero en paneles o diálogos
  • Productos de matemáticas con IA y paneles redimensionables
  • Experiencias adaptables entre escritorio y móvil

El usuario obtiene un tablero completo y con el tamaño correcto. El equipo de desarrollo necesita menos parches de diseño y consigue una integración más fiable.



Un modo de presentación más configurable

Poder presentar no significa que una sola interfaz sirva para todas las presentaciones.

Un docente puede necesitar el panel de diapositivas para cambiar de ejemplo. Un estudiante que revisa una solución quizá solo necesite el zoom. Una pantalla grande o una vista previa puede funcionar mejor sin herramientas, para mantener la atención en la geometría.

Dino-GSP SDK 2.10.0 añade tres opciones de interfaz al modo de presentación:

  • slidePanel controla el área de gestión de tableros.
  • pencilToolbar controla las herramientas docentes y de anotación.
  • zoomControl controla la interfaz de zoom.

Cada producto puede decidir qué controles aparecen en una clase, en el autoaprendizaje, en una vista previa o en una pantalla grande, conservando las acciones necesarias sin distraer.



Dónde aporta valor inmediato esta versión

  • Bancos de preguntas y SaaS educativo: genera diagramas uniformes para tarjetas, páginas de detalle y plantillas de examen, con menos capturas y recortes manuales.
  • Productos curriculares y de material didáctico: lleva los mismos datos geométricos por la edición, la presentación en clase, la exportación y la distribución.
  • Edición y escritura académica: genera TikZ directamente desde el tablero y conserva la capacidad de edición en un flujo profesional.
  • Productos de matemáticas con IA: ejecuta el tablero de forma fiable en vistas divididas, pestañas y paneles dinámicos.
  • Presentaciones y visores de contenido: ofrece a docentes, estudiantes y revisores la interfaz adecuada sin desarrollar un tablero distinto para cada rol.


Revisa estos tres puntos antes de actualizar

Al migrar a Dino-GSP SDK 2.10.0:

  1. Especifica size, view o contain en las llamadas de exportación de imágenes.
  2. Migra la exportación LaTeX/TikZ a editor.slides.exportLatex(options).
  3. Mueve el identificador de aplicación del modo de presentación desde appId en el nivel superior hasta auth.appId.
