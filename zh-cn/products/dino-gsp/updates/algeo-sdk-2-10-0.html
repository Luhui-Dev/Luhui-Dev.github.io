大角几何 SDK 重磅更新：让几何内容更好地导出与分发

产品: 大角几何画板

版本: SDK 2.10.0

发布日期: 2026年7月27日

最后修改: 2026年7月27日

把几何画板嵌入产品，只是第一步。

真正进入业务之后，团队往往还会遇到一连串更具体的问题：

  • 同一张图，怎样分别适配题库缩略图、试卷插图和高清课件？
  • 怎样只导出指定的坐标范围，而不是反复手动调整画布？
  • 几何图进入论文或教材后，能否继续编辑和排版？
  • 画板放在标签页、抽屉或折叠面板里，重新显示时为什么偶尔尺寸不对？
  • 演示页面能不能只保留教学真正需要的操作区？

这些问题看似分散，指向的其实是同一件事：几何内容如何稳定地走出画板，进入真实的内容生产、教学演示和产品交付流程。

大角几何 SDK 2.10.0 现已正式发布。本次更新围绕导出、动态布局适配和演示模式三个方向展开，让一份几何内容能够更顺畅地适配不同终端、不同版式和不同业务场景。



图片导出升级：按用途交付，而不只是导出一张图

在题库、课件、试卷和内容平台中，“导出图片”很少只有一种标准答案。

题库列表需要尺寸统一的缩略图；课件需要清晰、留白合理的高清图片；试卷插图需要稳定的构图范围；某些教学内容则只希望展示坐标系中的局部区域。

大角几何 SDK 2.10.0 为 editor.slides.exportImage(options) 新增三种导出模式：

  • size 模式：按指定尺寸输出，适合题库缩略图、内容卡片和固定版式课件。
  • view 模式：按指定世界坐标视野输出，可精确控制画面范围与比例，适合坐标系、函数图像和局部几何关系。
  • contain 模式：自动包围完整内容，减少图形被裁切或留白不均，适合批量导出形态差异较大的几何素材。

导出接口同时支持 PNG、JPG 和 SVG，并完善了 pixelRatio、padding、minPadding、quality 等参数。开发者不必再通过移动画布、缩放视野或导出后裁图来适配不同版式。同一份结构化几何数据，可以根据目标媒介直接生成相应的视觉结果。



LaTeX/TikZ 独立导出：让几何图进入专业排版流程

对于教材出版、试卷排版和学术写作来说，图片并不总是最终答案。

位图难以无损缩放，后期修改成本高；普通矢量图虽然清晰，却未必能自然融入 LaTeX 的字体、字号和版式体系。TikZ 能解决这些问题，但手工编写门槛高、耗时长。

在 2.10.0 中，LaTeX/TikZ 导出被拆分为独立接口：

editor.slides.exportLatex(options)

独立接口让图片导出与源码导出的职责更加清晰，也方便内容系统按目标渠道建立稳定流程：

  • 面向网页和课件，输出 PNG、JPG 或 SVG；
  • 面向论文、讲义和教材，输出可继续编辑、可参与排版的 LaTeX/TikZ；
  • 面向多渠道内容生产，由同一份几何源数据生成不同格式，避免重复绘制。

对于拥有大量数学内容的团队，这项能力的价值不只是节省一次作图时间，而是让几何素材具备一次生产、多端复用、长期维护的条件。



动态容器自动重绘：复杂页面里的画板更稳定

现代 Web 产品很少把画板放在一个始终可见、尺寸固定的页面中。它可能出现在题目编辑弹窗、课程标签页、侧边抽屉、折叠面板，或可自由调整宽度的工作区里。

大角几何 SDK 2.10.0 为 EmbeddedEditor 和 EmbeddedPresentation 新增 resize()，并使用 ResizeObserver 监听容器尺寸变化。当隐藏容器恢复可见时，SDK 会自动通知内嵌页面重新测量和绘制。

这一改进尤其适合：

  • 多标签页的题库与教研后台；
  • 使用抽屉、弹窗承载画板的出题工具；
  • 左右分栏、宽度可拖拽的 AI 数学产品；
  • 需要适配桌面端与移动端的响应式页面。

对用户来说，是画板打开后尺寸正确、内容完整；对开发团队来说，则意味着更少的布局补丁和更可靠的嵌入体验。



演示模式进一步开放：界面适配具体教学场景

“能演示”并不等于“适合所有演示”。

老师在课堂上可能需要画板列表快速切换例题；学生查看解题过程时，可能只需要缩放控件；大屏展示或内容预览中，则可能希望隐藏全部工具，让注意力集中在图形本身。

大角几何 SDK 2.10.0 为演示模式新增三项 UI 配置：

  • slidePanel：控制画板管理区域；
  • pencilToolbar：控制教具与书写工具栏；
  • zoomControl：控制缩放操作区。

产品可以根据课堂演示、学生自学、内容预览或大屏展示等场景，决定界面中出现哪些能力，既保留必要操作，也避免无关工具干扰用户。



这次更新为哪些场景带来直接价值？

  • 题库与教育 SaaS：批量生成规格统一的题卡、详情页和试卷配图，减少人工截图与二次裁切。
  • 教研与课件产品：同一份几何数据贯穿编辑、课堂演示、课件导出和资料分发。
  • 教材出版与学术写作：从画板直接生成 TikZ 源码，进入专业排版流程后仍可调整样式与结构。
  • AI 数学产品：画板能够稳定运行在分栏、标签页和动态面板中，降低尺寸错位与显示不完整的概率。
  • 教学演示与内容展示：按教师、学生和审核者的角色提供恰当的操作界面，无需分别开发多套画板。


升级前，请重点检查这三项配置

升级到大角几何 SDK 2.10.0 时，建议重点检查：

  1. 图片导出调用需要明确指定 size、view 或 contain 模式；
  2. LaTeX/TikZ 导出请迁移至 editor.slides.exportLatex(options)；
  3. 演示模式的应用标识请由顶层 appId 调整为 auth.appId。
